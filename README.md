# 家族カレンダー

家族の予定をみんなで管理するためのシンプルなカレンダーWebアプリです。
ビルド不要の素の HTML / CSS / JavaScript のみで作られており、`index.html` を開くだけで動作します。

## 主な機能

- 月表示・週表示・日表示の切り替え（週表示・日表示は縦軸=日付、横軸=時間のタイムライン形式）
- 複数日にまたがる予定（宿泊・旅行など）の作成にも対応
- 土曜日は水色、日曜日・日本の祝日はピンクで表示（祝日は振替休日・国民の休日を含めて自動計算）
- 家族メンバーの登録・編集・削除と、JIS基本10色からのカラー選択
- よく使う予定（テンプレート）の登録と、予定作成時のプルダウン選択
- 終日／時間指定、担当する家族（複数選択可）、メモ入力に対応
- 予定をクリックすると詳細（メモ含む）の確認・編集・削除ができるモーダルを表示
- 予定のコピー機能（似た予定をすぐに複製できます）
- 表示する家族メンバーを絞り込む機能
- スマートフォン・タブレット・PCに対応したレスポンシブデザイン
- （任意）Firebaseと連携して、家族のスマホ・PC間で予定をリアルタイム共有

## データの保存について

このアプリはサーバーを持たない静的サイトです。家族メンバー・テンプレート・予定のデータは、
**ブラウザの localStorage** に保存されます。

- 同じブラウザ・同じ端末であれば、閉じても再度開いてもデータは消えません。
- ただし、後述の「オンライン共有」を設定しない限り、**別の端末やブラウザとはデータが同期されません**
  （例：スマホで入力した予定はPCのブラウザには表示されません）。

## 複数端末での共有設定（Firebase・任意）

家族のスマホ・PC間で同じ予定をリアルタイムに共有したい場合は、無料のFirebaseプロジェクトを設定できます。
設定しない場合はこれまで通り、端末ごとの独立した保存（localStorageのみ）で動作します。

### 1. Firebaseプロジェクトを作成する

1. https://console.firebase.google.com/ をブラウザで開き、Googleアカウントでログイン
2. 「プロジェクトを追加」（画面表示によっては「Firebaseプロジェクトを設定して開始」）をクリックし、好きなプロジェクト名（例: `family-calendar`）を入力して作成
   （Googleアナリティクスは不要なのでオフのままで構いません）

### 2. Firestore Database を有効化する

1. 作成したプロジェクトの画面で、左メニュー「構築」（画面表示によっては「Database と Storage」）→ **Firestore**（**Firestore Database**）を開く
2. 「データベースの作成」をクリック
3. 「エディションを選択」と表示された場合は **Standard エディション** を選び、次へ（Enterpriseは大規模向けの高度なオプションのため不要です）
4. ロケーションは任意（日本から使うなら `asia-northeast1` 等）を選び、次へ
5. セキュリティルールは「本番環境モード」のまま作成してOK（ルールは後で設定します）

### 3. 匿名認証を有効化する

1. 左メニュー「構築」（画面表示によっては「セキュリティ」）→ **Authentication** を開く
2. 「始める」ボタンが表示された場合はクリックし、**「ログイン方法」**（**Sign-in method**）タブを開く
3. 「ネイティブのプロバイダ」欄の **匿名** をクリックし、有効にして保存

### 4. セキュリティルールを設定する

Firestore Database → 「ルール」タブを開き、以下の内容に書き換えて公開してください。
これにより「匿名ログイン済みの人だけ」がデータを読み書きできるようになります。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /families/{familyCode} {
      allow read, write: if request.auth != null;
    }
  }
}
```

> 注意: これは「共有コード（familyCode）を知っている人なら誰でも読み書きできる」簡易的な仕組みです。
> パスワードのように扱い、第三者に漏らさないよう共有コードを管理してください。
> より厳密なアクセス制御（家族単位のログイン認証など）が必要な場合は、匿名認証ではなくメール/パスワード認証やGoogleログインを導入し、
> セキュリティルールで「そのユーザー自身の家族データのみ」にアクセスを制限するような改修が別途必要です（本アプリの標準機能には含まれていません）。

### 5. Webアプリを登録し、設定値を取得する

1. 左メニュー上部の歯車アイコン **「設定」** をクリックする（「プロジェクトの設定」画面が開きます）
2. 「マイアプリ」で `</>`（ウェブ）アイコンをクリック
3. 「アプリのニックネーム」に好きな名前（例: `マイ ウェブアプリ` のままでもOK）を入力
4. 「このアプリのFirebase Hostingも設定します」のチェックは**入れずに**、「アプリを登録」をクリック
5. 表示される `firebaseConfig` の中の値（`apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`）を、`js/firebaseConfig.js` の該当箇所に書き写す

```js
global.FC_FIREBASE_CONFIG = {
  apiKey: '...',
  authDomain: '...',
  projectId: '...',
  storageBucket: '...',
  messagingSenderId: '...',
  appId: '...',
};
```

これらの値はFirebaseの仕組み上、外部に公開されても問題ない値です（実際のアクセス制御はステップ4のセキュリティルールが担っています）ので、そのままリポジトリにコミットして構いません。
このリポジトリには既にこのアプリ用のFirebaseプロジェクトの値が設定済みです。別のFirebaseプロジェクトを使いたい場合のみ、上記の書き換えが必要です。

### 6. アプリ側で接続する

1. 家族カレンダーアプリの **⚙ 設定** を開く
2. 一番下の「オンライン共有（複数端末で同期）」セクションで、「共有コード」に家族で共通の合言葉を入力（「自動生成」ボタンでランダムな文字列を作ることも可能）
3. 「接続する」を押す
4. **2台目以降の端末**では、**同じ共有コード**を入力して接続してください。既存のデータがある場合は「共有データを使う／この端末のデータで上書きする」の確認が表示されます

以降は、いずれかの端末で予定を追加・編集すると、他の端末にもリアルタイムに反映されます。
共有をやめたい場合は、設定画面の「切断してこの端末だけで使う」から解除できます。

共有コードはパスワード代わりなので、家族以外に共有しないようにしてください。

## ローカルでの動作確認

`index.html` をブラウザで直接開くだけで動作します。より確実に動かす場合は、簡易サーバーを立てて確認してください。

```bash
# 例：Pythonがある場合
python3 -m http.server 8000
# その後 http://localhost:8000/ を開く
```

## GitHub Pages への公開手順

1. このフォルダの内容をGitHubリポジトリにpushする
2. リポジトリの Settings → Pages を開く
3. Source を「Deploy from a branch」、Branch を `main` / `root(/)` に設定して保存
4. しばらくすると `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## ファイル構成

```
index.html              画面のHTML本体
css/style.css           スタイル（レスポンシブ対応）
js/utils.js             日付・時間・色に関する共通処理
js/holidays.js          日本の祝日計算（振替休日・国民の休日を含む）
js/storage.js           localStorageへの保存・読み込み、JIS基本10色パレット
js/state.js             家族メンバー・テンプレート・予定のデータ管理（CRUD）
js/firebaseConfig.js    Firebaseプロジェクトの接続設定（固定値）
js/sync.js              Firebase Firestoreを使ったオンライン共有（任意設定）
js/filter.js            表示する家族メンバーの絞り込み（端末ごとの表示設定）
js/modal.js             モーダルダイアログの共通土台
js/views/month.js       月表示
js/views/timeline.js    週表示・日表示（タイムライン）
js/views/eventForm.js   予定の新規作成・編集・コピー・詳細確認フォーム
js/views/settings.js    設定画面（家族メンバー・テンプレート管理）
js/views/memberFilter.js 表示メンバー絞り込みボタン・ドロップダウン
js/app.js               全体のコントローラー（表示切替・ナビゲーション）
```
